# 现实练级 · 林间远征

私人运动驱动像素RPG试玩版。角色成长、运动结算、锻造、六个遭遇和回合制战斗均可操作。

**GitHub Pages 纯前端试玩：** https://heracles1983.github.io/real-leveling/

**Site 完整版：** https://real-leveling-rick.heracles1983.chatgpt.site

Pages 版无需平台登录，进度保存在当前浏览器，并支持 CSV / JSON 本地导入；Site 版提供 D1 私人云存档与 Intervals.icu 服务端同步。

## 玩法

- 演示冒险内置三条示例运动；真实冒险独立保存。
- 每分钟2经验，每条最多80；按上海日期每天最多150经验、2枚符石。升级获得2个自由属性点。
- 力量增加攻击，耐力增加生命和部分能量，敏捷提高暴击。所有运动类型使用相同经验规则。
- 战斗：普通攻击回能、重击穿甲、防御减伤、药水恢复45%生命。除首个敌人外，每三回合敌人重击。
- 首次通关掉落金币和符石；重复挑战不重复奖励。营地补满药水，每日首次额外10金币。
- 六个区域依次解锁；战败、撤退或休息不会扣除永久成长。

## 数据与存档

存档保存在平台D1数据库，按平台提供的稳定用户ID与模式隔离。操作在服务端计算并使用revision比较更新，避免多窗口重复领奖。接口拒绝未登录访问。

个人试用版支持：

1. Intervals.icu个人API Key：通过同源服务端接口读取最近30天记录。Key仅保留在打开页面的内存中，临时传给服务器，不写入数据库、浏览器持久存储或日志。
2. CSV / JSON 导入：支持 id、name、type、start_date_local、moving_time（秒），或 start、minutes（分钟）。无时区时间按上海时间解释。最多250条、500KB。

同ID或开始时间相近且大幅重叠的记录去重。只保存游戏需要的标题、类型、日期、时长，不保存路线、心率。手动导入属于自报数据，当前版本不是竞赛计分系统。客户端显示的模拟初始状态在读取存档成功前不可操作。

本版仅作个人试用。向多个客户开放前应按Intervals.icu的要求使用OAuth，不应让多人填写个人API Key。佳明/Apple Health直连未实现；手表需先同步到支持的运动平台。

## 开发与验证

- 保留所附Vinext、React与Cloudflare Workers构建结构。
- `npm run build` 构建Worker与静态资源。
- `npx tsc --noEmit` 检查类型。
- `node --experimental-strip-types --test tests/game-rules.test.mjs` 检查奖励上限、跨设备去重、日期校验、导入、战斗门槛、休息和完整章节通关。
- 数据库由 `db/schema.ts` 和 `drizzle/` 迁移管理；不在请求中创建表。

美术位于 `public/art/`，由图像生成工具创作。角色图集在Canvas中按单元格提取并去除洋红背景。音效由浏览器合成，默认关闭。

真实账户同步需由用户在页面输入自己的Key后验证；目前没有使用任何真实账户凭据进行端到端同步测试。
